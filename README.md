## The entry

> My weekend left a note: 'Gone. Monday ate me.'

One line, 46 characters — a joke about Monday mornings, chosen by a
head-to-head tournament over 18 candidates (8 from Hermes, 10 built
locally) judged on the house criteria: really about Monday mornings,
punchline that lands, surprise, economy of words, freshness. See
[CANDIDATES.md](CANDIDATES.md) and [TOURNAMENT.md](TOURNAMENT.md).

## How it works

`main.py` (stdlib only) writes the winning line to
`$MAKEFUN_OUTPUT_DIR/entry.txt`. It never writes into the repository
itself. A length guard asserts the text stays exactly 46 characters.
